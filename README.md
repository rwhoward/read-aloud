# read-aloud

Personal Claude Code skills that rewrite technical documents as HTML pages written for listening with Microsoft Edge's Read Aloud. They translate for the ear rather than summarizing. Lists, tables, code, and diagrams become narrated prose. The originals stay on the page in figures marked `aria-hidden`, which Read Aloud skips, and long lookup material goes on a separate reference card.

There are two skills:

- **`read-aloud`** creates the listening pages.
- **`read-aloud-clean`** prunes the library. It archives documents, which hides them from the index and keeps their files. It deletes them, by moving them to the Recycle Bin, only when you explicitly ask.

Packaging these as an installable plugin is planned but not done. See [docs/plugin-packaging.md](docs/plugin-packaging.md).

## Requirements

- Windows. The skills are built and tested only on Windows.
- Microsoft Edge, for Read Aloud.
- Python 3.7 or later, available as `python`. The script needs only the standard library.
- Git, optionally. When a source file is in a git repo, the repo's name becomes the library folder the document is filed under.

## Install

Clone the repo, then link both skill folders into the global Claude Code skills folder. From the clone's root in PowerShell:

```powershell
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
New-Item -ItemType Junction -Path "$HOME\.claude\skills\read-aloud" -Target "$PWD\skills\read-aloud"
New-Item -ItemType Junction -Path "$HOME\.claude\skills\read-aloud-clean" -Target "$PWD\skills\read-aloud-clean"
```

## Uninstall

Remove the two junctions with `rmdir`, which deletes only the link:

```powershell
cmd /c rmdir "$HOME\.claude\skills\read-aloud"
cmd /c rmdir "$HOME\.claude\skills\read-aloud-clean"
```

Don't use `Remove-Item -Recurse` on a junction in Windows PowerShell 5.1. It can delete the files in the clone as well. Uninstalling leaves the library at `~/ReadAloud` alone, so delete that folder yourself if you want it gone.

## Use

Ask Claude something like "make this doc something I can listen to", or run `/read-aloud`. Then press Ctrl+Shift+U in Edge.

Generated pages go to `~/ReadAloud/<project>/<date>_<slug>/`, outside every repo, including this one. Set `READ_ALOUD_HOME` to move the library. `~/ReadAloud/index.html` lists everything that has been generated, with links straight to each part. It's worth bookmarking.

Every page ends with a Sources list linking to the original documents and the saved copies. When a page combines several documents, small numbered markers show which part came from which. Read Aloud skips both.

To tidy up, ask something like "clean up my read aloud notes", or run `/read-aloud-clean`.

## Privacy

- Each document keeps copies of its sources in its `source/` folder. They stay there after an archive, until the document is deleted.
- Each page's Sources list shows the full local path of every original file.
- Pages load the Atkinson Hyperlegible font from Google Fonts. Pages with Mermaid diagrams also load Mermaid from jsDelivr, so offline those diagrams show as plain text.
- Edge's voices with "Online (Natural)" in their names are generated by Microsoft's cloud speech service, so the page text is sent to Microsoft. For confidential documents, pick a voice without "Online" in its name. Those run on your machine.
- Each page's Content-Security-Policy blocks scripts other than its own, images from the web, and outgoing requests.

## Layout

- `skills/read-aloud/SKILL.md` covers the workflow and the writing-for-the-ear rules.
- `skills/read-aloud/references/examples.md` has before and after conversions.
- `skills/read-aloud/scripts/read_aloud.py` is shared by both skills. It needs only the Python standard library, and it handles:
  - `init` and `build`: the page template, the speakability, safety, and fidelity checks, and opening Edge
  - `library`: the index page
  - `list`, `archive`, `restore`, and `delete`: cleanup
- `skills/read-aloud-clean/SKILL.md` covers the cleanup workflow.
- `tests/test_read_aloud.py` tests the script. Run the tests from the clone's root with `python -m unittest discover -s tests`. They use a temporary library and never open Edge or touch the Recycle Bin.
